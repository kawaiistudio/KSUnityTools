# Kawaii Studio Link

Links this Unity project with the Kawaii Studio app (VRChat Archive). Open `Kawaii Studio > Kawaii Studio Link`.

- **Send to Unity**: the app's Scene Editor exports straight into this project (`Assets/Kawaii Studio/KS Exported`).
- **Test in Kawaii Studio**: builds the selected avatar, or the open world scene, and opens it in the app's Scene Editor.

Works in avatar and world projects. Part of [KS Unity Tools](https://github.com/kawaiistudio/KSUnityTools); this package alone has no VRChat SDK dependency.
